# Raghu Anand - Portfolio

A clean, minimal portfolio website built with Next.js and TypeScript.

## Overview

Simple personal portfolio showcasing my experience, education, and projects as a Full-Stack Software Engineer.

## Tech Stack

- **Next.js 14** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

## Build

```bash
npm run build
npm start
```

## Customization

Update your information in `constants/index.tsx`:
- Personal details
- Experience and education
- Projects
- Social links
