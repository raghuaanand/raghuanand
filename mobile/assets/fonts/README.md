# Font Assets

This folder contains custom fonts for the mobile app.

## Required Fonts

Download these fonts and place them in this directory:

### Inter (Body Text)
- `Inter-Regular.ttf`
- `Inter-Medium.ttf`
- `Inter-SemiBold.ttf`

Download from: https://fonts.google.com/specimen/Inter

### Crimson Pro (Display/Headings)
- `CrimsonPro-Regular.ttf`
- `CrimsonPro-SemiBold.ttf`
- `CrimsonPro-Italic.ttf`

Download from: https://fonts.google.com/specimen/Crimson+Pro

### IBM Plex Mono (Code)
- `IBMPlexMono-Regular.ttf`

Download from: https://fonts.google.com/specimen/IBM+Plex+Mono

## Installation

1. Visit Google Fonts and download each font family
2. Extract the TTF files
3. Rename them to match the names above exactly
4. Place them in this `fonts/` directory

The fonts are loaded in `app/_layout.tsx` using `expo-font`.
